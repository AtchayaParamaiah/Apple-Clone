# 🍎 Apple Clone

A modern, responsive Apple-inspired landing page built with **React, Vite, and Tailwind CSS**. This project recreates Apple's clean and minimal design style as a front-end development practice project.

## 🌐 Live Demo

🔗 **[View Live Website](https://apple-clone-4go7805bl-atchaya-projects1.vercel.app/)**

## ✨ Features

- 🍎 Apple-inspired website design
- 📱 Responsive layout for different screen sizes
- 🎨 Modern UI with clean typography and styling
- ⚛️ Built using React components
- 💨 Fast development and production builds with Vite
- 🎯 Tailwind CSS for styling
- 🚀 Deployed using Vercel

- **React** – Component-based user interface

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/AtchayaParamaiah/Apple-Clone.git
```

### 2. Navigate to the Project Folder

```bash
cd Apple-Clone
```

If the project files are inside a nested `Apple-Clone` folder, navigate into that folder containing `package.json`.

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.

### 5. Build for Production

```bash
npm run build
```

Vite generates the production-ready files in the `dist` directory.
